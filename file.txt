Build a complete, modern, responsive web application for the following hackathon problem statement:

Google Antigravity powered App that solves for societal benefit by helping individuals recognize unusual patterns in their daily lives before they become larger problems. Participants must create a functional interface that accepts unstructured personal data such as expenses, study hours, sleep patterns, or health logs and instantly converts them into structured insights by detecting anomalies, highlighting significant deviations, and providing easy-to-understand explanations.

==================================================
TECH STACK & CONSTRAINTS
==================================================
• Use React.js with JavaScript (NOT TypeScript)
• Do NOT use TypeScript anywhere
• Keep the backend minimal or completely optional
• Prefer a frontend-only solution using local state + browser localStorage
• If any backend is absolutely required, use a lightweight Node.js + Express server with in-memory storage only
• Do NOT use MongoDB, Firebase, Supabase, SQL, or any cloud database
• Do NOT use authentication or login systems
• Hardcode all datasets, rules, sample data, thresholds, and configurations
• The application must work completely offline after load (PWA-friendly if possible)
• Use modern React (functional components + hooks)
• Setup using Vite + React
• Use Tailwind CSS for styling
• Use Lucide-react for iconography
• Use Recharts for clean, responsive data visualization
• Use date-fns for relative human dates ("2 hours ago", "Yesterday at 11:30 PM")
• Use uuid for unique IDs

==================================================
APP NAME & POSITIONING
==================================================
App Name: LifeSignal
Tagline: Spot the small shifts before they become big problems.

LifeSignal is a calm, personal early-warning system. Users log unstructured daily entries (expenses, sleep, study, mood, symptoms, habit logs). The app structures the data, detects anomalies, explains patterns in warm human language, and suggests gentle preventive actions — client-side, private, and offline.

==================================================
DATA MODEL (LOCALSTORAGE BASE)
==================================================
Schema for logs:
{
  id: string,
  timestamp: ISO string,
  category: "expenses" | "sleep" | "study" | "health" | "mood" | "fitness" | "custom",
  subcategory: string,
  rawText: string,                 // e.g., "Spent 450 on late night swiggy dinner"
  value: number | null,            // e.g., 450
  unit: string | null,             // e.g., "INR", "hrs", "steps", "score"
  tags: string[],
  moodScore: number | null,        // 1-10
  notes: string,
  source: "manual" | "quick" | "demo",
  createdAt: ISO string
}

Also store user preferences (thresholds, dark/light theme, alert settings, dismissed alerts).

==================================================
SMART INGESTION ENGINE (UNSTRUCTURED → STRUCTURED)
==================================================
Build a friction-free "Quick Capture" drawer/modal with 3 modes:

1. Free-Text Natural Language Parser (Client-side Regex + Keyword Mapping):
Examples to support seamlessly:
• "slept only 4.5 hours woke up tired" → Sleep | 4.5 | hours | Tags: [tired, short-sleep]
• "spent 1200 at starbucks with friends" → Expenses | 1200 | INR | Subcategory: Coffee/Food
• "studied dsa for 3.5 hours" → Study | 3.5 | hours | Subcategory: Coding
• "migraine headache since 3pm took tablet" → Health | Symptom: Migraine
• "feeling anxious mood 3/10" → Mood | 3 | score
• "walked 3200 steps today" → Fitness | 3200 | steps

2. Structured Tap Input: Category dropdown, value input with auto-filling unit, tag selection pills.
3. Confirmation Card: Shows a human preview ("We parsed this as **₹1,200** under **Expenses**") with quick 1-tap edits before saving.

==================================================
ANOMALY DETECTION & HUMAN EXPLANATION ENGINE
==================================================
Calculate rolling baselines (7-day, 14-day, 30-day averages, std dev, day-of-week patterns).

Detection Rules (sensible defaults, adjustable in Settings):
• Expenses: Single item > 2.5x 7-day average, or 3+ consecutive days of food delivery spikes.
• Sleep: Drop of > 1.5 hours vs personal mean, or 3+ consecutive nights < 6 hours.
• Study: Focus drop > 40% vs average, or overwork (> 10 hrs) leading to low mood.
• Health/Mood: 2+ consecutive low mood days (≤ 3/10) or recurring physical symptoms.
• Cross-Category Correlations:
  - Low Sleep → Next-day high expenses / low study output.
  - Late-night study → Poor sleep score.
  - Dehydration + headache co-occurrence.

Explanation Design:
Never output raw formulas like "Z-score = 2.4". Output warm, thoughtful human insights:
• "You've slept an average of 5.1 hours over the last 3 nights — roughly 2 hours less than your baseline. Short sleep streaks often show up before focus drops."
• "Food ordering spending is up 2.2x this week. Noticeably, 3 of these orders occurred after 11 PM following low-mood entries."
